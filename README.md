# Места, где я не был

Личное приложение-мечта: карта мест, которые я не просто хочу посетить,
а проработал — прочитал, собрал точки, маршруты, картинки.

- Одна мечта = одна папка (`Уганда/`, `Перу/`): в ней `мечта.md` с описанием,
  точками, книгами и маршрутами, и папка `доска/` с картинками (подпись = имя файла).
  Новая мечта — новая папка по тому же образцу, скрипт найдёт её сам.
- `макеты/make_mockup.py` — собирает из папок макет: PDF и веб.
- `docs/` — веб-версия для GitHub Pages: `index.html`, манифест, иконки и `sw.js`,
  благодаря которому страница с домашнего экрана iPhone открывается без сети.

Сборка веб-версии:

    python3 -I макеты/make_mockup.py <папка с GeoJSON Natural Earth> docs/index.html '{}' web
