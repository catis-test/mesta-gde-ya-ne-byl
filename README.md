# Места, где я не был

Личное приложение-мечта: карта мест, которые я не просто хочу посетить,
а проработал — прочитал, собрал точки, маршруты, картинки.

- `docs/index.html` — веб-версия макета, публикуется через GitHub Pages.
- `макеты/make_mockup.py` — скрипт, который собирает макет (PDF и веб) из данных.
- `Уганда/доска`, `Перу/доска` — картинки для досок, подпись берётся из имени файла.

Сборка веб-версии:

    python3 -I макеты/make_mockup.py <папка с GeoJSON Natural Earth> docs/index.html '{}' web
